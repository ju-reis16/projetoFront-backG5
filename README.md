## Como rodar o Front  
- Acesse a pasta do front-end: `cd frontend`  
- Instale as dependências: `npm install`  
- Inicie a aplicação: `npm start`  
- Acesse no navegador: `http://localhost:3000`  

## Como rodar o Back  
- Acesse a pasta do back-end: `cd backend`  
- Instale as dependências: `npm install`  
- Inicie o servidor: `npm run dev` ou `npm start`  
- Acesse: `http://localhost:5000`  

## Observações  
- É necessário ter o Node.js instalado  
- Verifique se as portas 3000 e 5000 estão disponíveis  
- Configure o arquivo `.env` (se houver) antes de rodar o projeto
